# Developer Guide

## Commands

- `nix fmt` - Format code
- `nix flake check` - Run checks (format, lint, type-check, tests)
- `cd frontend && pnpm test` - Run tests
- `cd frontend && pnpm run preview:cf` - Preview build on the Cloudflare Workers runtime
- `cd frontend && pnpm run deploy` - Build and deploy to Cloudflare Workers
